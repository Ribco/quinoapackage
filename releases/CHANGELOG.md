
# QuinoaUI Changelog

## v1.1.0 — Initial Release

### Added
- Modern Dark and Light themes.
- Draggable windows.
- Window minimize, close, open, and toggle controls.
- Multiple tabs.
- Sections and labels.
- Buttons and toggles.
- Sliders.
- Dropdowns and multi-dropdown API.
- Text inputs.
- Notifications.
- Basic component cleanup.
- GitHub-based Studio installer.

### Notes
- This is the first public release.
- More components and improvements are planned.
