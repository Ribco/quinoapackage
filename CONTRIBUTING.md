# Contributing to QuinoaUI 💚

Thank you for your interest in contributing to QuinoaUI!

We welcome bug reports, feature suggestions, documentation improvements, and code contributions.

## Before Contributing

- Check existing issues before reporting a new one.
- Make sure your changes are related to QuinoaUI.
- Test your changes in Roblox Studio.
- Keep code readable and organized.

## Reporting Bugs

If you discover a bug:

1. Open the repository's Issues page.
2. Select **Bug Report**.
3. Describe the problem.
4. Include reproduction steps.
5. Include any relevant Roblox Studio output or errors.

[Report a bug](https://github.com/Ribco/quinoapackage/issues/new?template=bug_report.yml)

## Suggesting Features

Have an idea for QuinoaUI?

1. Open the Issues page.
2. Select **Feature Request**.
3. Explain the feature and why it would be useful.
4. Include examples if possible.

[Suggest a feature](https://github.com/Ribco/quinoapackage/issues/new?template=feature_request.yml)

## Code Contributions

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes.
4. Test your code in Roblox Studio.
5. Commit your changes with a descriptive message.
6. Open a Pull Request.

## Code Style

When contributing Luau code:

- Use clear and descriptive variable names.
- Keep functions organized.
- Avoid unnecessary code duplication.
- Handle errors appropriately.
- Preserve compatibility with existing QuinoaUI features.
- Include comments when they help explain complex behavior.

## Pull Requests

Please include:

- A clear description of your changes.
- The reason for the changes.
- Testing information.
- Screenshots or recordings for visual changes when possible.

Pull requests may be reviewed, modified, or declined by the maintainers.
